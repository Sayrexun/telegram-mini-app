# Telegram Mini App — каталог

Это полноценный стартовый шаблон обычного каталога товаров:
- адаптивный интерфейс под Telegram;
- поиск;
- категории;
- карточки товаров;
- корзина (демо);
- серверная база SQLite;
- админ-панель;
- добавление, скрытие и удаление товаров;
- Telegram WebApp API.

## Запуск

Нужен Node.js 18+.

```bash
npm install
ADMIN_KEY="придумай-сложный-ключ" npm start
```

Открой `http://localhost:3000`.

Админка: `http://localhost:3000/admin.html`

## Подключение к Telegram

Для Telegram Mini App нужен публичный HTTPS-адрес. После размещения приложения на хостинге укажи URL в настройках Web App у своего бота через BotFather.

## Важно

В этом шаблоне оформление заказа оставлено демонстрационным. Не подключай оплату/заказ к товарам, продажа которых ограничена возрастом или иным законодательством.

Перед публичным запуском:
- замени ADMIN_KEY на длинный случайный секрет;
- используй HTTPS;
- добавь нормальную авторизацию администратора;
- проверь Telegram `initData` на сервере, если будешь использовать данные пользователя;
- настрой резервное копирование `catalog.db`.

Примечание: `toggle()` в демо-админке намеренно показан упрощённо; для продакшена лучше сделать отдельный PATCH endpoint для изменения только `active`.
